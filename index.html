Combine all four "engines": understanding (Feynman) → memorization (flashcards + spacing) → retrieval → application (practice questions).

Five methods — each with a distinct job

✎

Active Recall

Strongest evidence base. Retrieve before revealing — the core mechanism behind every other method.

◷

Spaced Repetition

Software schedules reviews right when you're about to forget. Ideal for formulas, definitions, classifications.

▣

Flashcards

The vehicle for the two above. Cloze cards for formulas, "when to use" cards to disambiguate concepts.

✦

Feynman

Understanding engine. Explain in plain language → exposes gaps. Best for the hardest readings.

❖

Mindmap

Organize interconnected concepts; drawing one from memory is itself a large retrieval workout.

📚 Setup guide — link your materials in 4 steps

  1. Upload your Schweser / GARP / AnalystPrep / Bionic PDFs to your personal Google Drive (or OneDrive, Dropbox).
  2. For each file: right-click → Share → set access to "Anyone with the link" (keep it unlisted — don't post the link publicly).
  3. Copy the shareable link.
  4. In the Reading below, click the matching source button (Schweser / GARP / etc.) and paste the link. Next time you click that button, the PDF opens straight in a new tab. Sources with a saved link are marked ✓.
